New to software testing certifications? This page shows a simple order to follow, and a short questionnaire suggests where you should begin.

Where to start

  1. Learn the basics. Read the CTFL study guides, one chapter at a time:
    • fundamentals
    • testing in the SDLC
    • static testing
    • test techniques
    • cheat sheet
    • test management
    • test tools
  2. Practice mode on CTFL. Answer questions chapter by chapter with instant explanations in CTFL practice. No timer, no pressure.
  3. Exam mode. When practice scores are steady, take timed simulations from the same page to get used to the clock. Read the exam tips first.
  4. Next levels. Build on the Foundation level; see below.

What each certification is for

  • Foundation Level (CTFL): the common starting point. Shared vocabulary and core ideas of testing. Good for anyone entering QA or working with testers.
  • Agile Tester: how testing works in agile teams. A sensible second step if you work in (or want to join) a Scrum or similar team.
  • Advanced level: deeper, role-based certifications:
    • Test Analyst: test design and analysis
    • Technical Test Analyst: white-box and technical quality characteristics
    • Test Manager: planning, monitoring and leading a team
  • Specialist: focused topics:
    • Test Automation
    • Performance Testing

Suggested order:

  1. CTFL
  2. Agile Tester (if you work in agile)
  3. An Advanced or Specialist module that matches your role

Typically CTFL is needed before Advanced. Prerequisites and experience requirements vary, so check the official body for current rules.
